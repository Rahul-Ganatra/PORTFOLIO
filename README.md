# Rahul Ganatra Portfolio

Vanilla HTML, CSS, and JavaScript portfolio for Rahul Jignesh Ganatra.

## Run locally

Open `index.html` directly, or serve this folder with any static HTTP server:

```bash
python -m http.server 5173
```

The site includes responsive navigation, project filtering, project carousel controls,
skills tabs, active section tracking, scroll reveals, and an optional persisted dark theme.

## Required hero artwork

The approved reference calls for these artwork assets, but they are not present in the
provided project: `hero-car.webp`, `mountains.svg`, `road.svg`, and `speedometer.svg`.
The hero currently shows dimensioned, clearly labeled placeholders for each missing layer
instead of substituting unrelated artwork or a cropped screenshot.
